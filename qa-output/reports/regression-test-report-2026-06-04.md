| 属性 | 值 |
|------|-----|
| **严重等级** | 一般 |
| **模块** | 护士端 / 系统设置 / 科室管理 |
| **复现步骤** | 1. 以管理员登录护士端 2. 点击"系统设置" 3. 进入"科室管理"页面 4. 查看浏览器控制台 |

| **实际** | 控制台报错 `Uncaught (in promise)` at DepartmentsPage.vue:159 |
| **影响** | 不影响页面功能展示，但 Promise 未捕获可能导致静默失败 |

### ISSUE-002：护士端 TypeScript 构建失败（22+ 错误）

| 属性 | 值 |
|------|-----|
| **严重等级** | 严重 |
| **模块** | 护士端全局 |
| **复现步骤** | 运行 `corepack pnpm --filter nurse-app build` |
| **预期** | 构建成功 |
